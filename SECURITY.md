# Segurança

Não abra issues públicas contendo vulnerabilidades exploráveis, dados pessoais, tokens ou credenciais. Utilize um canal privado acordado com a pessoa responsável pelo repositório; nenhum endereço de segurança foi formalizado.

Esta versão é exclusivamente DEMO local. Não implantar como serviço financeiro. A proteção de startup recusa produção e dinheiro real, mas não substitui segregação de rede, revisão, autenticação, autorização e homologação.
